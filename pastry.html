Pastry

A clipboard manager that lives in your Mac's menu bar. Keep track of what you've copied, organize snippets into folders, and paste them with a keyboard shortcut.

View on the Mac App Store Visit Pastry's website ↗

Key features

1. Clipboard History
Automatically saves recent clips so you can get back to something you copied earlier.
2. Global Hotkeys
Paste saved clips from other apps with keyboard shortcuts, without opening the menu each time.
3. Folders for Snippets
Keep text you reuse in named folders, with your clipboard data stored locally on your Mac.
4. Native macOS Architecture
Built with Swift and SwiftUI using MVVM to separate the interface from the app's state and logic. AppKit APIs support clipboard monitoring, global hotkeys, and persistent, folder-based snippet storage.
